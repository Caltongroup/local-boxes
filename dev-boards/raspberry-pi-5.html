Raspberry Pi 5

Broadcom BCM2712, four Cortex-A76 cores at 2.4GHz, up to 16GB LPDDR4X, a PCIe 2.0 ×1 lane for an M.2 SSD, and the standard 40-pin header. The default Linux board for anything that has to sit next to hardware all day.

What it is

Raspberry Pi’s current flagship board. BCM2712 quad-core 64-bit Arm Cortex-A76 at 2.4GHz with 512KB L2 per core and 2MB shared L3, VideoCore VII GPU (OpenGL ES 3.1, Vulkan 1.3), dual 4Kp60 HDMI, dual-band 802.11ac Wi-Fi and Bluetooth 5.0. I/O goes through Raspberry Pi’s own RP1 controller. Raspberry Pi says it is up to three times faster than Pi 4, adds a power button and a battery-backed real-time clock, and commits to production until at least January 2036.

Who it is for

Builders who want a small, well-documented Linux box with GPIO: home automation, sensor hubs, robots, kiosks, a self-hosted agent or MCP server, or the always-on “brain” that talks to a bigger local-AI box. Wrong if the plan is to run real language models on the board itself; there is no NPU or CUDA, and memory bandwidth is phone-class.

Where it fits in a local-AI or hardware build

  • As the glue: a 24/7 Linux host on the LAN that runs scripts, Home Assistant-style automation, or an agent loop, and sends inference requests to a real local box such as a Framework Desktop or DGX Spark.
  • As the hardware edge: the 40-pin header, two 4-lane MIPI camera/display connectors and the PCIe lane let it read sensors and cameras, then hand data to a model somewhere else.
  • On-board models: the 16GB board can hold small quantized models on CPU, but expect it to be slow. Treat it as a toy or a fallback, not a daily driver. (Our read, not a benchmark.)

Standout details

  • 16GB is the top RAM option; 1GB to 8GB also ship.
  • PCIe 2.0 ×1 needs a separate M.2 HAT or adapter. Gigabit Ethernet supports PoE+ with a separate HAT.
  • 2× USB 3.0 run at 5Gbps simultaneously.
  • Raspberry Pi recommends a 5V 5A supply (its 27W USB-C unit); Pi 4 supplies may underpower it.
  • Raspberry Pi says it performs best with active cooling, and it will not fit a Pi 4 case.
  • Runs Raspberry Pi OS Trixie (current) and Bookworm (legacy); older releases do not support it.

Which model we picked

Raspberry Pi 5, the current flagship of the numbered line. It has the newest Raspberry Pi silicon (BCM2712 plus RP1), the only Pi with a PCIe lane, RAM up to 16GB, and a stated production life to January 2036. Source: raspberrypi.com/products/raspberry-pi-5.

Honest verdict

Buy the Pi 5 if you want the safest Linux board for hardware projects and an always-on helper next to your local-AI box. Get 8GB or 16GB if it will run containers or an agent stack. Do not buy it to run LLMs; pair it with a box from the directory instead.
