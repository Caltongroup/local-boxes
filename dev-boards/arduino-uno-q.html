Arduino UNO Q (4GB)

Two brains on an UNO-sized board: a Qualcomm Dragonwing QRB2210 running Debian Linux, and an STM32U585 microcontroller running Arduino sketches on Zephyr. One board for the AI app and the real-time pins.

MPU
Qualcomm Dragonwing QRB2210, 4× Cortex-A53 @ 2.0GHz
MCU
STM32U585, Cortex-M33 up to 160MHz
Memory / storage
4GB LPDDR4 / 32GB eMMC (2GB / 16GB variant too)
Radio
Wi-Fi 5 dual-band, Bluetooth 5.1
Power
USB-C 5V 3A, or VIN 7–24V
Catch
One USB-C port; A53-class CPU

What it is

Arduino’s Linux-plus-microcontroller board in the classic UNO footprint (68.85 × 53.34 mm). The Qualcomm Dragonwing QRB2210 (quad-core Cortex-A53 at 2.0GHz, Adreno GPU, dual ISP) runs a full Debian Linux with upstream support. An STM32U585 (Cortex-M33 up to 160MHz, 2MB flash, 786KB SRAM) runs Arduino sketches on Zephyr for deterministic I/O. A built-in RPC library, Arduino Bridge, links the two. Arduino App Lab ties Python apps, sketches and AI models into one workflow, and Docker and Docker Compose are supported on the Linux side.

Who it is for

Arduino users who have outgrown a plain microcontroller and want Linux, Python and a camera on the same board as their shields. It also suits teachers and anyone prototyping an edge-AI gadget that has to drive motors or read sensors in real time. Wrong if you want a desktop-class SBC; Arduino recommends the 4GB variant for standalone desktop use.

Where it fits in a local-AI or hardware build

  • As a self-contained edge-AI gadget: Linux side runs Python and the vision or audio model through App Lab; the MCU side runs motors, LEDs and sensors with real-time timing.
  • As a front end to a bigger box: the Linux side can call a local model on a directory box over Wi-Fi while the MCU keeps the hardware loop tight.
  • Arduino’s store page pitches deploying pre-trained models to the Qualcomm AI engine from App Lab. That is vision- and sound-class work, not LLM chat. (Our read, not a benchmark.)

Standout details

  • The single USB-C port handles host/device role switching, power role switching and video out. With a powered USB-C dongle it drives HDMI, keyboard, mouse, camera, Ethernet and storage.
  • Keeps UNO headers for stacking shields; adds a Qwiic connector and bottom high-speed connectors for carriers with MIPI-CSI cameras, MIPI-DSI displays and audio.
  • An 8×13 blue LED matrix, 4 RGB user LEDs and a user button on board.
  • Interfaces include I2C/I3C, SPI, PWM, CAN, UART, PSSI, GPIO, JTAG and ADC.
  • Program the MCU alone from Arduino IDE 2.0+, or both sides from Arduino App Lab (Windows 10+, macOS 11+, Ubuntu 22.04+ or Debian Trixie).

Which model we picked

Arduino UNO Q, 4GB RAM / 32GB eMMC variant. It is the larger of the two UNO Q SKUs, and Arduino recommends the 4GB variant for single-board-computer use. The 2GB / 16GB version is the same board with less memory. Sources: docs.arduino.cc UNO Q, Arduino Store, UNO Q 4GB.

Honest verdict

Buy the UNO Q 4GB if you want Arduino’s shield world and a Linux AI app on one board without wiring a Pi to an UNO. Buy the 2GB if it is a single-purpose node. Skip it if you need a fast general-purpose Linux machine; a Pi 5 or Orange Pi 5 Max has far more CPU.
