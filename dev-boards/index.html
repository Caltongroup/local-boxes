Dev Boards

The starter kit for vibe coding hardware.

You can describe a gadget to a coding agent and have firmware in minutes. You still need boards on the desk. These five cover a Linux host, a beefier edge node, a Wi-Fi microcontroller, a Linux-plus-Arduino hybrid, and a long-range radio.

How they fit with a local box

None of these replaces a local-AI machine. The model runs on a box from the directory. The boards are the hands, ears and radios around it. A microcontroller reads a sensor, a Linux board runs the agent loop, and both call the big box on your LAN. Specs on each page come from the maker’s own site, with sources cited. No prices; they move.

Raspberry Pi 5

The safe Linux board with GPIO. Up to 16GB, PCIe for NVMe.

Type
Linux SBC
Chip
BCM2712, 4× A76
Memory
Up to 16GB

Always-on host

Buy for the glue and the GPIO. Not for running LLMs.

ESP32-S3 + SX1262 LoRa, OLED, battery charger.

Type
LoRa node
Chip
ESP32-S3 + SX1262
Memory
8MB flash, no PSRAM

Long-range link

Buy for Meshtastic and LoRaWAN. It is the radio, not the brain.

A sane first kit

  • One Linux board (Pi 5 or Orange Pi 5 Max) as the always-on helper.
  • Two or three ESP32-S3 boards for sensors, buttons and relays.
  • An UNO Q if you live in Arduino shields and want Linux on the same board.
  • A pair of Heltec LoRa boards if anything has to talk beyond Wi-Fi range. LoRa nodes need a partner to talk to.
